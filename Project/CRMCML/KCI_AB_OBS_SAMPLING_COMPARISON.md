# KCI·A/B·OBS 표본추출 방식 비교

## 표 1. KCI·A/B·OBS 표본추출 방식 비교

| 구분 | KCI 첨부 코드 | 폴더 A/B | 폴더 OBS |
|---|---|---|---|
| 표본 단위 | 메시지 행 | 고객(`client_id`) | 고객(`client_id`) |
| 모집단 | 반송·차단되지 않은 전체 메시지 | 지정된 A/B 캠페인 노출 고객 | A/B 캠페인에 노출되지 않은 고객 |
| 구매자(1) 추출 | 전수 포함 | A/B 캠페인 구매 고객 전수 포함 | 비-A/B 구매 고객 중 최대 20,000명 |
| 비구매자(0) 추출 | 모든 비구매 메시지 행의 37% 무작위 추출 | 구매자 1명당 최대 10명, 비복원 추출 | 비구매 고객의 1.5% 추출 |
| 구매자 포함확률 | 1.0 | 1.0 | min(20,000, N1) / N1 |
| 비구매자 포함확률 | 0.37 | min(10×N1, N0) / N0 | 0.015 |
| 추출 알고리즘 | 난수 기반 Bernoulli 추출 | 고객 ID 해시 우선순위 `bottom-k` 비복원 추출 | 고객 ID 해시 기반 결정적 확률추출 |
| 고객 전체 이력 보존 | 아니오. 동일 고객의 일부 메시지만 남을 수 있음 | 예. 선택 고객의 전체 메시지 이력 보존 | 예. 선택 고객의 전체 메시지 이력 보존 |
| A/B 캠페인 처리 | 별도 구분 없음 | 처치·대조 캠페인 유지 | 모든 A/B 캠페인 및 A/B 노출 고객 제외 |
| 표본가중치 | 기록하지 않음 | 1 / 포함확률 기록 | 1 / 포함확률 기록 |
| 주된 분석 목적 | 일반 구매예측용 불균형 완화 | 처치효과/uplift 추정 | 구매확률 모델 학습 후 A/B에 점수 전이 |

## 표 2. 표본 분포와 해석 비교

| 항목 | KCI 첨부 코드 | 폴더 A/B | 폴더 OBS |
|---|---|---|---|
| 구매율 변화 | 구매 행은 전수, 비구매 행은 37%만 유지되어 원자료보다 약 2.7배 높아짐 | 고객 기준 구매자:비구매자 비율을 최대 1:10으로 구성 | 구매자·비구매자의 포함확률이 달라 원자료 구매율이 변형됨 |
| 고객 표집 기준 구매자 비율 공식 | 해당 없음: 메시지 행을 직접 추출 | N1 / [N1 + min(10×N1, N0)] | (π1×N1) / [(π1×N1) + (0.015×N0)] |
| 고객 표집 기준 구매자 비율 | 해당 없음 | 비구매 고객이 충분하면 9.0909%; 부족하면 9.0909%보다 높음 | 실제 N1, N0에 따라 달라짐 |
| 최종 메시지 행 구매율 | 코드 목표 약 0.1234%* | **0.254551%** (2,459 / 966,013) | **0.412836%** (33,629 / 8,145,854) |
| 공변량 분포 | 구매·비구매 메시지 행 내부 분포는 대체로 보존되나 전체 혼합분포는 변형 | 구매·비구매 고객 내부 분포는 대체로 보존되나 전체 고객 혼합분포는 변형 | 동일 |
| 시간·이력 분포 | 일부 메시지 행이 삭제되어 고객별 시계열 이력이 끊길 수 있음 | 고객 단위 전체 이력 보존 | 고객 단위 전체 이력 보존 |
| 처치·대조 분포 | 없음 | 처치·대조를 별도로 균형추출하지 않으므로 원자료 비율과 달라질 수 있음 | 없음 |

\* KCI의 0.1234%는 코드의 목표값이다. 비구매 행을 37% 확률로 추출하므로 실제 실행값은 약간 달라질 수 있다.

여기서 N1은 모집단의 구매 고객 수, N0는 모집단의 비구매 고객 수, π1은 OBS 구매 고객의 포함확률[min(20,000, N1) / N1]이다.

> **주석:** A/B의 “구매자 1명당 비구매자 최대 10명”은 고객 표집 규칙이다. 최종 파일은 선택 고객의 전체 메시지 이력을 포함하므로, 고객 기준 구매자 비율과 최종 메시지 행 구매율(0.254551%)은 서로 다른 값이다.

## 핵심 설명

- **KCI**는 메시지 한 통씩 뽑는다. 구매 메시지는 모두 남기고 비구매 메시지는 37%만 남기므로, 같은 고객의 메시지 이력이 중간중간 사라질 수 있다.
- **A/B**는 실험 메시지를 받은 고객을 뽑는다. 구매 고객은 모두, 비구매 고객은 최대 10배까지 선택한 뒤 선택 고객의 메시지 이력을 전부 보존한다. 목적은 “처치 메시지가 누구에게 더 효과적인가”를 분석하는 것이다.
- **OBS**는 A/B에 노출되지 않은 일반 고객을 뽑는다. 구매확률을 학습해 A/B 분석에 보조점수로 활용하는 자료다.
- A/B의 1:10은 **고객 수 기준**이다. 최종 파일에는 고객별 전체 메시지가 들어가므로, 메시지 행 기준 구매율 0.254551%와는 다른 값이다.

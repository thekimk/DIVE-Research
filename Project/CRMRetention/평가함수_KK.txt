🏆 1. AUUC (Area Under the Uplift Curve)시각화로 보셨던 Gain Curve 아래의 면적을 하나의 숫자로 압축한 점수입니다. 일반적인 머신러닝의 AUC(ROC Curve 면적)와 같은 역할을 합니다.
비교 방법: Model A(기존)와 Model B(신규)의 AUUC 점수를 계산하여, "신규 변수를 추가함으로써 타겟팅 정확도(AUUC)가 몇 % 포인트 상승했다"고 증명할 수 있습니다.
🎯 2. Top $K\%$ 타겟팅 시의 예상 추가 구매 수 (Expected Incremental Conversions)현실의 마케팅은 예산의 한계 때문에 전체 고객의 10%~20%에게만 캠페인을 발송합니다. 따라서 전체 성능보다 "최상위 점수를 받은 유저들을 타겟팅했을 때의 성과"가 훨씬 중요합니다.
비교 방법: 상위 20% 유저를 추출한 뒤, 이들의 CATE 점수를 모두 더합니다.
해석: "기존 모델로 상위 20%를 타겟팅하면 캠페인으로 인해 250건의 추가 구매가 발생하지만, 내가 만든 신규 모델로 상위 20%를 골라내면 380건의 추가 구매가 발생합니다. 즉, 마케팅 효율이 52% 개선되었습니다."
🛡️ 3. 역효과 방어율 (Negative CATE Avoidance)이전 그래프에서 우리는 하위 10~15% 유저들에게 캠페인을 보냈을 때 엄청난 역효과(수직 낙하)가 발생함을 확인했습니다. 신규 변수들이 이 '분노하는 유저(청개구리)'들을 얼마나 더 잘 걸러냈는지 수치화합니다.
해석: "신규 모델은 마케팅 역효과가 예상되는 유저를 기존 모델보다 $X$명 더 정확히 식별해내어, 불필요한 마케팅 발송 비용 절감 및 고객 이탈을 방어했습니다."

Table 1. $K$-Fold 교차 검증을 통한 성과 비교 (Robustness Check)단일 Test Set 결과는 학술적으로 신뢰받지 못합니다. 데이터를 5개(또는 10개)로 쪼개어 반복 학습한 뒤, AUUC의 평균($\mu$)과 표준편차($\sigma$)를 보고해야 합니다.

리뷰어 방어 논리: "왜 곡선이 출렁이는가?"만약 심사위원이 "Gain Curve 중간이 왜 이렇게 파도치듯 출렁이나요? 모델이 불안정한 것 아닙니까?"라고 묻는다면, 다음과 같이 멋지게 방어하실 수 있습니다.
"관측 데이터 기반의 DML 특성상, 대부분의 대중(Mass) 고객은 해당 정책에 대해 한계 기여도(CATE)가 0에 수렴하는 '무반응(Neutral) 그룹'입니다. (Heterogeneity Plot 제시)무반응 그룹 구간에서는 누적 이득이 본질적으로 랜덤 워크(Random Walk)의 형태를 띨 수밖에 없으므로 곡선이 출렁이는 것은 통계적 필연입니다.
본 연구의 핵심 기여(Contribution)는 전체 곡선의 매끄러움이 아니라, 곡선 초반부의 가파른 상승(Steep initial slope)을 통해 정책에 유의미하게 반응하는 '숨겨진 상위 10~20%의 타겟 집단'을 성공적으로 분리해 냈다는 점에 있습니다."

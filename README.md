> **"여러분들이 여러분 스스로를 포기하지 않는 한, 나는 여러분들을 절대로 먼저 포기하지 않습니다!!!"**

- DIVE (Data Insights for Visionary Empowerment) Group은 디지털경제의 표준이 되어가고 있는 빅데이터와 인공지능 이론을 활용하여,     
비즈니스와 사회의 다양한 문제를 데이터를 기반으로 정량적으로 분석하고 의사결정함으로써 전략적으로 문제를 해결하기 위한 방법을 연구합니다.

- DIVE 멤버만이 누릴 수 있는 혜택!
1) 소그룹 학술 지원사업 획득가능 + 교수학생 전공심화 연구 지원사업 + 탐구 커뮤니티 지원사업 등 소정의 생활비 획득 가능
2) 글로벌 해외 탐방 견학 및 지원금 획득 가능 (타과생은 약 50% 자부담 발생)
3) 김경원 교수님 수업 조교 활동 기반 소정의 생활비 획득 가능 (GTS학부생만 가능)
4) 공모전 또는 학회발표 수상을 통한 사회문제 해결역량 증명 가능
5) KCI/SCI/SSCI 연구논문 사회문제 해결역량 증명 가능
6) 창업계획서 기반 정부지원금 획득 가능
7) 졸업 후에도 지속가능한 데이터 및 AI 기반 동료 획득
